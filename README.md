## 🌸 About This Project
This is an extraordinarily crafted, highly animated, romantic digital birthday experience built exclusively for **Chhavi**. It is designed as a magical interactive digital greeting card and storybook consisting of 10 interconnected scenes:

1. **Scene 1: A Magical Welcome 🎀** — Floating hearts, twinkling stars, cute animated teddy bear holding a gift, and gentle opening reveal.
2. **Scene 2: The Envelope Experience 💌** — Interactive pink envelope with a 3D wax seal ("C"), realistic unfolding letter with the late-wish developer codebase joke, and Niranjan's sign-off.
3. **Scene 3: The Birthday Cascade 🎂** — Celebratory confetti, floating balloons, interactive birthday cake with tap-to-extinguish candles, and 5 interactive wish cards.
4. **Scene 4: Our Little Memory Scrapbook 📸** — Vintage Polaroid photo frames with washi tape, stickers, and interactive fullscreen lightbox modal. (Easily customizable in `src/data/photos.ts`).
5. **Scene 5: Words From My Heart 💗** — 4 handwritten love letters on romantic vintage stationery (*Aapki Ahmiyat*, *Meri Favourite Insaan*, *Aap Aur Main*, *Meri Ek Khwahish*).
6. **Scene 6: Shayari, Sirf Aapke Naam 🌙** — Dreamy twilight poetry book with crescent moon, glowing stars, and 5 original Hinglish/Urdu-inspired shayaris.
7. **Scene 7: Little Things I Love About You 🧸** — 9 interactive cards highlighting her smile, quirks, habits, and presence, paired with a reactive animated teddy companion.
8. **Scene 8: The Birthday Gift 🎁** — Beautifully wrapped 3D pink gift box with untying ribbons, flying lid, golden glow, confetti burst, and emotional birthday card.
9. **Scene 9: A Final Romantic Message ✨** — Floating lanterns and starlit sky expressing why she makes life beautiful.
10. **Scene 10: Ek Chhoti Si Maafi, Meri Jann Ke Naam 🥺❤️** — The heartfelt, sincere, humble apology letter, 3 handwritten promise cards, and unconditional love without pressure.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies (already installed)
npm install

# 2. Start the development server
npm run dev
```

Visit `http://localhost:5173` on your computer or phone browser on your local WiFi!

## 📸 How to Add Your Real Photos

1. Drop your pictures into the `public/images/` folder:
   - `public/images/chhavi-1.jpg`
   - `public/images/together-1.jpg`
   - `public/images/cute-moment.jpg`
   - `public/images/memory-special.jpg`
   - `public/images/favorite-us.jpg`
2. Open [src/data/photos.ts](file:///Users/niranjansingh/Desktop/projects/HAPPY%20BIRTHDAY/src/data/photos.ts)
3. Set the `image` string for each item, e.g.:
   ```ts
   image: "/images/chhavi-1.jpg",
   ```
4. Save the file. Your photos will immediately show in the Polaroid scrapbook! If left blank, the app displays aesthetic illustrated placeholders so nothing ever looks broken.

## 🌐 1-Click Free Deployment (To send Chhavi a link)

### Option A: Vercel (Easiest)
1. Push this folder to a GitHub repository or install Vercel CLI (`npm i -g vercel`).
2. Run `vercel` in terminal and follow prompts.
3. You will get a live link like `https://chhavi-birthday.vercel.app` to share with her!

### Option B: Netlify
1. Drag and drop the `dist/` folder directly to [Netlify Drop](https://app.netlify.com/drop).
2. It goes live instantly with a free URL!
